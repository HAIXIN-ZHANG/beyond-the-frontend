## Design System 判断

55 个项目变量分属 primitives、semantic colors、space/radius；语义颜色通过 alias 引用原始颜色。变量有明确 scopes 与 WEB syntax。共有 14 个 text styles 和 2 个 effect styles。页面使用可编辑文字与组件，没有整页截图代替 UI。

本项目组件层次为基础/语义、基础组件、阅读模式和页面组合。不是所有文字、图形或 Frame 都要变成组件：具体章节图示属于内容；TOC 项和搜索结果可根据实现中的复用需求继续收敛。此边界能避免维护多份 Header/提示块，同时不增加无用途的抽象。

Button、IconButton 提供 Default/Hover/Focus/Disabled；目录项提供 Default/Selected/Hover/Focus；Header 提供 Desktop/Compact/Narrow；ThemeControl 提供 Light/Dark。具体清单与节点见 [设计交接](../design/reading-experience-v1.md)。PandaCSS 已由用户指定；Park UI/Ark UI 仍是按需采用的实现建议，本轮未安装或迁移。

## 可访问性与证据边界

18 组实际解析后的 token 配色计算均达到本轮目标：普通文字 4.5:1、控件边界 3:1。浅色/暗色正文对画布约 13.79/16.26，次要文字约 5.35/9.10，按钮文字约 6.86/12.04。参照 [WCAG 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum)。44px 是本项目的操作区域约定，不将其错误表述为所有 WCAG AA 场景的统一要求；参见 [目标大小说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)。

轻透材质仅用于导航，正文实色；减少透明度与不支持 blur 的环境回退实色，主题默认跟随系统。风格参考 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 与 [Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode)，不是复刻原生系统或宣称符合全部 Apple HIG。

尚未验收：真实 DOM 语义、焦点顺序/归还、模态焦点范围、键盘操作、200%/400% 文字缩放、屏幕阅读器、移动浏览器、主题初始化闪白、持久化及动态透明背景的全部叠色。这些是实施验收项，不要求为设计阶段虚构通过结果。

Figma 账号权限不能隔离同一 Owner 账号授权的不同 agent。没有声称只有“本人操作”才可写入；项目角色边界与用户授权仍有效。

## Design-system judgment

At that checkpoint, 55 variables across primitives/semantic colors/space-radius used aliases, explicit scopes and WEB syntax, with 14 text/two effect styles. Editable text/components were retained rather than page-image replacement.

The project layers were primitives/semantics, basic components, reading patterns and composition. Not every text/vector/frame needed a component; chapter diagrams remain content, and TOC/search can consolidate around actual reuse. This avoids duplicate headers/callouts without purposeless abstraction.

Button/IconButton had Default/Hover/Focus/Disabled; navigation Default/Selected/Hover/Focus; Header Desktop/Compact/Narrow; ThemeControl Light/Dark. See the [design handoff](../design/reading-experience-v1.md) for nodes. PandaCSS was author-selected, Park/Ark optional suggestions; no installation/migration occurred in UI02.

## Accessibility and evidence limits

Eighteen resolved token color pairs met the selected targets: normal text 4.5:1, control boundaries 3:1. Body/canvas Day/Night were approximately 13.79/16.26, secondary text 5.35/9.10, button text 6.86/12.04. Reference: [WCAG text contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum). A 44px target is this project's convention, not a universal WCAG AA requirement; [target-size guidance](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum).

Translucency stays in navigation while prose is solid, with opaque fallback for reduced transparency/no blur; system theme is default. [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) and [Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode) were references, not native-system replication/full-HIG claims.

Still unaccepted: DOM semantics, focus order/return/trapping, keyboard, 200%/400% text zoom, screen readers, mobile browsers, first-theme flash, persistence and every translucent composition. These belong to implementation acceptance, not invented design-stage passes. Same-owner account authorization does not isolate agents; role scope/user authorization remains necessary.
